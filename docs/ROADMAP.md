# Roadmap

All items below are PLANNED.

- Unit tests for every rule family.
- Tune on dev only; re-score test once and record it.
- First npm release by hand, then trusted publishing, so `npx rithik` works (docs/RELEASING.md).
- PyPI release through trusted publishing (docs/RELEASING.md), so `pipx install rithik` works.
- Tighten the Python `task_job_offer.task` pattern (1.8 s on a 1 MB adversarial input).
- Hindi and Telugu script support.
- A small real-world labelled set, with consent, to replace or supplement the synthetic one.
- An Android share-sheet version and a browser extension that use the same rules.
